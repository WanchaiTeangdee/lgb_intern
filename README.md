# 💌 เว็บความทรงจำฝึกงาน — จากน้องตี๋ & น้องหมวย

หน้าแรกให้พี่ๆ กดเลือกชื่อตัวเอง → เปิดซองจดหมาย → อ่านจดหมายถึงตัวเอง + ดูความทรงจำรวมของน้องฝึกงานกับพี่ๆ LGB ทุกคน (รูปและคลิป)

## ดูเว็บบนเครื่อง

ดับเบิลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งอะไร (แก้ไฟล์แล้วกด F5 เพื่อดูผล)

## ไฟล์ที่ต้องเขียน

| ไฟล์ | เขียนอะไร |
| --- | --- |
| `letters.js` | จดหมายถึงพี่ทั้ง 26 คน แต่ละคนมีช่องของตี๋และหมวยแยกกัน แต่ละฉบับใส่ข้อความ (`text`) และรูป/คลิป (`media`) ได้ ช่องไหนว่างไว้จะไม่แสดง |
| `memories.js` | ความทรงจำรวม "น้องฝึกงานกับพี่ๆ LGB ทุกคน" + รูป + คลิป และคลิปตัดต่อก่อนท้ายหน้า (`MEMORY_VIDEO`) ทุกคนเห็นเหมือนกัน อยู่ในหน้าที่มีปุ่มพาไปจากท้ายหน้าแรก ถ้ายังว่างจะขึ้นว่า "เร็วๆ นี้" |
| `data.js` | ชื่อพี่ๆ, emoji, สีประจำตัว, หัวเว็บ, ข้อความปิดท้าย, คำพูดของตัวการ์ตูนหน้าแรก (`mascots`), **รายการเพลงประกอบ (`MUSIC`)** |
| `reply-characters.js` | รูปการ์ตูนประจำตัวพี่แต่ละคนในกล่องตอบกลับ แยกเพศตาม `gender` ใน `data.js` |
| `farewell.js` | ฉากตัวการ์ตูนส่งน้องที่ล่างสุดของหน้าความทรงจำ และหัวใจกับดาวที่ลอยไปหาน้องๆ เมื่อกดปุ่ม |

วิธีเขียนและตัวอย่างอยู่ในคอมเมนต์ด้านบนของแต่ละไฟล์

ความทรงจำใน `memories.js` ไม่ต้องใส่วันที่ เพราะหนึ่งเรื่องอาจรวมเหตุการณ์หลายวันได้ เว็บเรียงเรื่องตามลำดับบล็อกในไฟล์ อยากย้ายเรื่องไหนขึ้นก่อนให้ย้ายทั้งบล็อก

จดหมายทุกซองลงท้ายด้วย “น้องตี๋ & น้องหมวย” ตามค่า `SITE.from` ใน `data.js` แม้จะเขียนแยกช่องกัน

## รูปและคลิป

| ใส่ที่ | ใช้กับ |
| --- | --- |
| `images/people/<id>.jpg` | รูปโปรไฟล์พี่ เช่น `images/people/natto.jpg` วางแล้วขึ้นเองเลย |
| `media/` | รูปและคลิปของความทรงจำรวม แล้วใส่ชื่อไฟล์ใน `media: [...]` |

- รูป: `.jpg` `.png` `.webp` แนะนำย่อให้กว้างไม่เกิน ~1600px
- คลิป: `.mp4` ดีที่สุด (คลิป `.mov` จาก iPhone บางเครื่องเปิดไม่ได้ ควรแปลงก่อน)
- คลิปยาวหรือไฟล์ใหญ่: อัปขึ้น YouTube แบบ Unlisted แล้วใส่ลิงก์แทนได้เลย
- ชื่อไฟล์ใช้ภาษาอังกฤษ ไม่มีเว้นวรรค และตรงตัวพิมพ์เล็ก/ใหญ่ (`.jpg` ≠ `.JPG` เมื่อขึ้นเว็บจริง)
- หาไฟล์ไม่เจอ เว็บไม่พัง จะแสดง emoji แทน

แต่ละ `title` ใน `memories.js` ใส่รูปได้หลายรูปใน `media` ของเรื่องนั้น รูปแรกเป็นภาพใหญ่ รูปที่เหลือเป็นรูปเล็กด้านล่าง กดรูปไหนก็ขยายดูและใช้ปุ่มลูกศรดูรูปต่อไปได้

ตัวอย่างใส่รูป 3 รูปในเรื่องเดียวกัน เปลี่ยนชื่อไฟล์ให้ตรงกับรูปที่วางไว้จริงใน `media/`:

```js
media: [
  "media/first-day-01.jpg",
  "media/first-day-02.jpg",
  "media/first-day-03.jpg",
],
```

## คลิปตัดต่อก่อนท้ายหน้าความทรงจำ

ส่วน "คลิปความทรงจำของเรา" อยู่หลังเรื่องเล่าทั้งหมด ก่อนปุ่มกลับหน้าแรก ตัดต่อเสร็จแล้ววางไฟล์ `.mp4` ใน `media/` เช่น `media/memories-film.mp4` แล้วตั้งค่า `MEMORY_VIDEO` ที่ต้น `memories.js`:

```js
const MEMORY_VIDEO = {
  src: "media/memories-film.mp4",
  poster: "", // ใส่รูปปกได้ เช่น "media/memories-film-cover.jpg"
};
```

ให้แก้บล็อกเดิมในไฟล์ ไม่ต้องเพิ่มบล็อกซ้ำ ถ้า `src` ยังว่างจะมีข้อความรอคลิปแทน กดเล่นแล้วคลิปจึงเริ่ม มีปุ่มพัก เลื่อนเวลา และดูเต็มจอ เพลงพื้นหลังหยุดชั่วคราวระหว่างดู แล้วเล่นต่อเมื่อพัก จบคลิป หรือออกจากหน้า ถ้าไฟล์คลิปเปิดไม่ได้จะเปลี่ยนเป็นข้อความแทน

## เพลงประกอบ

เพลงเล่นต่อเนื่องจากเพลงที่ 1 → 2 → 3 แล้ววนกลับเพลงแรกไปเรื่อยๆ เล่นต่อเนื่องข้ามทุกหน้า มีปุ่มกลมมุมขวาล่างสำหรับ หยุด/เล่น และข้ามเพลง

- เว็บจะลองเปิดเพลงอัตโนมัติทันทีที่เข้า ถ้าเบราว์เซอร์บล็อกเสียง เพลงจะเริ่มเมื่อพี่ๆ แตะที่ไหนก็ได้ในหน้า (เช่นตอนกดเลือกชื่อ) กดปุ่ม ⏸ เพื่อหยุดเพลงได้ รวมถึงระหว่างที่เพลงกำลังโหลด
- ถ้าพี่คนไหนกดหยุดเพลงไว้ เว็บจะจำและไม่เปิดเองในครั้งต่อไป
- ตอนเปิดดูคลิปในแกลเลอรี เพลงจะหยุดชั่วคราวและเล่นต่อเมื่อปิดคลิป
- คลิปตัดต่อก่อนท้ายหน้าความทรงจำจะหยุดเพลงระหว่างเล่นด้วย และคืนเพลงเมื่อพักหรือจบคลิป โดยเคารพการกดหยุดเพลงของผู้ชม
- เพลงจาก YouTube ต้องเปิดผ่านเว็บจริงและมีอินเทอร์เน็ต ส่วนไฟล์ `.mp3` ในเว็บเล่นได้ทั้งตอนเปิด `index.html` ตรงๆ และตอนเปิดผ่านเว็บ
- ⚠️ เจ้าของเพลงบางรายปิดการฝัง YouTube บนเว็บอื่น เพลงนั้นจะเล่นไม่ได้และเว็บข้ามไปเพลงถัดไปเอง กดปุ่ม 🎶 มุมล่างเพื่อดูรายการเพลงและสถานะของแต่ละเพลง (เพลงที่ฝังไม่ได้จะมีป้ายกำกับ)
- ทางออกที่เล่นได้แน่นอน: ใช้ไฟล์เสียงของเราเอง วางไฟล์ `.mp3` ไว้ใน `media/music/` แล้วเขียนใน `MUSIC` ว่า `{ src: "media/music/ชื่อไฟล์.mp3", title: "ชื่อเพลง" }` ผสมกับเพลง YouTube ได้
- เปลี่ยน/เพิ่มเพลงที่ `MUSIC` ใน `data.js` อยากปิดเพลงใส่ `MUSIC = []`

## ตัวการ์ตูนน้องตี๋ & น้องหมวย

หน้าแรกเริ่มที่หัวเว็บ พอเลื่อนลงมาจะไหลลงไปอยู่ขอบซ้าย (ตี๋) / ขวา (หมวย) ของจอ และอยู่ตรงนั้นทุกหน้า กดที่ตัวเพื่อให้กระโดดได้ แก้ชื่อ/คำพูดที่ `mascots` ใน `data.js` หรือใส่ `mascots: null` เพื่อซ่อน

## ฉากส่งน้องท้ายหน้าความทรงจำ

ล่างสุดของหน้า `#/memories` มีกลุ่มพี่ๆ LGB อยู่ฝั่งซ้าย และน้องตี๋กับน้องหมวยอยู่ฝั่งขวา กดปุ่ม "ส่งน้องตี๋กับน้องหมวย" แล้วหัวใจกับดาวจะลอยไปหาน้องๆ จากนั้นน้องๆ โบกมือตอบ กดส่งใหม่ได้เมื่อแอนิเมชันจบ ระหว่างเห็นฉากนี้ ตัวการ์ตูนที่ติดขอบจอจะหลบให้ชั่วคราว

กล่องคำพูดจะซ่อนไว้ก่อนกดปุ่ม ฝั่งพี่ๆ พูดทันทีเมื่อเริ่มส่ง และฝั่งน้องๆ ตอบเมื่อรับหัวใจแล้ว คำพูดทั้งสองค้างไว้จนกดส่งใหม่หรือออกจากหน้า

ปุ่มนี้เป็นลูกเล่นบนหน้าเว็บ ไม่ได้ส่งข้อความหรือบันทึกข้อมูล ถ้าตั้ง `SITE.cute = false` หรืออุปกรณ์เปิดโหมดลดการเคลื่อนไหว ฉากและปุ่มยังใช้ได้ โดยแสดงข้อความตอบรับแทนเอฟเฟกต์เคลื่อนไหว โค้ดอยู่ใน `farewell.js` และรูปตี๋กับหมวยใช้ชุดเดียวกับ `mascots.js`

## กล่องตอบกลับ + กระดานโน้ต (admin.html)

ท้ายจดหมายของพี่แต่ละคนมีกล่อง "ส่งข้อความกลับมาหาน้องๆ" พี่พิมพ์แล้วกดส่ง ข้อความจะเข้า Google Form/Sheet ของเรา (พร้อมชื่อพี่เจ้าของหน้า) คนอื่นไม่เห็น

เหนือช่องพิมพ์มีตัวการ์ตูนพี่เจ้าของจดหมายอยู่ทางซ้าย และน้องตี๋กับน้องหมวยอยู่ทางขวา พี่ทั้ง 26 คนมีทรงผม เสื้อผ้า และเครื่องประดับต่างกัน โดยตั้งเพศใน `PEOPLE` ด้วย `gender: "female"` หรือ `gender: "male"` และปรับรูปลักษณ์ตาม `id` ใน `reply-characters.js` (โหลดก่อน `app.js`) ตัวการ์ตูนนี้เป็นภาพวาดตกแต่ง ไม่ได้สร้างจากรูปโปรไฟล์

เมื่อพิมพ์ข้อความแล้วกดส่ง จดหมายจะบินจากพี่ไปหาน้องๆ ระหว่างส่งจะกดซ้ำหรือแก้ข้อความไม่ได้ ถ้าเกิดข้อผิดพลาด ข้อความเดิมจะยังอยู่ให้ลองส่งอีกครั้ง ร่างข้อความจำแยกตามพี่ในเครื่องที่ใช้ ถ้าเปิดโหมดลดการเคลื่อนไหวหรือตั้ง `SITE.cute = false` จะส่งได้ตามปกติโดยไม่มีแอนิเมชัน ขณะเห็นกล่องตอบกลับ ตัวการ์ตูนติดขอบจอจะหลบให้ชั่วคราว

เปิดอ่านได้ที่ `admin.html` เป็นกระดานโน้ตสีน่ารัก ต้องพิมพ์รหัสลับก่อนจึงจะเห็น (ลิงก์: `https://<เว็บของเรา>/admin.html` ไม่มีปุ่มพาไปจากหน้าเว็บหลัก)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `data.js` → `SITE.reply` | ตั้งค่าฟอร์มที่รับข้อความ (`action`, `nameField`, `messageField`) ถ้าเว้นว่างไว้ กล่องจะไม่แสดง |
| `admin.html` `admin.js` `admin.css` | หน้ากระดานโน้ต (กรองตามพี่ เรียงเวลา กดหัวใจ ♥ เก็บโน้ตที่ชอบ — หัวใจจำไว้ในเครื่องที่ใช้) |
| `tools/replies-apps-script.gs` | ต้นฉบับโค้ด Google Apps Script ที่ส่งข้อความจาก Sheet ให้หน้า admin (คัดลอกไปวางใน Apps Script ไม่ได้ทำงานในเว็บ) |

ตั้งค่าครั้งแรก
1. สร้าง Google Form มีช่อง "ชื่อพี่" กับ "ข้อความ" แล้วเอา `action` และรหัส `entry.xxxxxxxxxx` ของแต่ละช่องไปใส่ใน `SITE.reply`
2. เปิด Sheet ที่รับคำตอบ → ส่วนขยาย → Apps Script → วางโค้ดจาก `tools/replies-apps-script.gs` แล้วแก้ `KEY` เป็นรหัสลับ → Deploy เป็น "เว็บแอป" (เรียกใช้ในฐานะ: ฉัน / ผู้มีสิทธิ์เข้าถึง: ทุกคน)
3. เอา URL ที่ลงท้าย `/exec` ไปใส่ที่ `NOTES_URL` ใน `admin.js`

ข้อควรระวัง
- ⚠️ ใส่รหัสลับ (`KEY`) ใน Apps Script เท่านั้น ห้ามใส่ในไฟล์ในโฟลเดอร์นี้ เพราะโฟลเดอร์นี้จะถูกอัปขึ้นเว็บ และห้ามตั้ง Sheet เป็นสาธารณะ
- เว็บบอกไม่ได้ว่าข้อความเข้าฟอร์มจริงไหม (Google Form ไม่ส่งผลกลับ) ควรลองส่งจากหน้าเว็บจริงก่อนปล่อย แล้วลบแถวทดสอบใน Sheet (อย่าลบแถวหัวตาราง)
- ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy เวอร์ชันใหม่ (จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่)
- หน้า admin ป้องกันด้วยรหัสลับเท่านั้น ไม่ใช่ระบบล็อกอินเต็มรูปแบบ ตั้งรหัสให้เดายาก

## เช็กว่าพิมพ์ผิดไหม

เปิดเว็บแล้วกด F12 → แท็บ Console ถ้ามี id ซ้ำใน `data.js` หรือ `letters.js` อ้าง id ที่ไม่มี จะมีคำเตือนสีเหลืองบอกว่าผิดตรงไหน
ถ้าหน้าเว็บขาวทั้งหน้า แปลว่าไฟล์ .js มีจุดพิมพ์ผิด (เช่น ลืม `,` หรือ `` ` ``) Console จะบอกบรรทัดที่ผิด
